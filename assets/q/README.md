# Козаки з наборів Quaternius

- `kozak.glb` — герой (~56 тис. трикутників разом з усіма частинами одягу, текстури 1024).
- `voin.glb` — воїн загону, спрощений (~5½ тис. трикутників на видимого простого воїна, текстури 512).

Джерела, усі безкоштовні під ліцензією CC0 (можна в будь-якій грі, згадувати автора не обов'язково):
- Universal Base Characters: тіло й голова, вуса вирізано з бороди.
- Modular Character Outfits – Fantasy: вбрання «Селянин» і «Лучник». Лучника перефарбовано із зеленого в коричневий.
- Universal Animation Library 1 і 2: рухи.

Автор наборів — Quaternius, https://quaternius.com

Частини одягу — окремі сітки. Гра вмикає й вимикає їх (див. `Q_PARTS` в `index.html`):
- `Peasant_*` / `Chest` — сорочка, штани, постоли, відкриті груди;
- `Ranger_*` / `Undershirt` — жупан, пояси, наплічник, наручі, чоботи, каптур, сорочка під жупаном;
- `Head`, `Usy` — голова (лиса) і довгі козацькі вуса;
- `Shar_0..4` — шаровари (сині, червоні, зелені, чорні, оксамитові);
- `SashS_0..4`, `SashV_0..4` — кушак на сорочку та на жупан (червоний, синій, зелений, чорний, золотий);
- сорочка — вишиванка (`MI_Shirt`), кольчуга — `Mail_*`;
- `Weapon` → `Wpn_0..4` — шабля, меч, бойова сокира, лицарський меч, клинок короля (у правій руці);
- `Shield` → `Shield_0..2` — дерев'яний, окутий, із тризубом (на лівому передпліччі);
- `Helm` → `Helm_1..3` — козацька шапка, залізний шолом, шишак.

Зброю, щити, шоломи й вуса зроблено кодом (`tools/q/qitems.mjs`). Шолом облягає голову. Шаровари, кушак і вишиванку робить `tools/q/qcossack.mjs`. Колір чобіт і обладунку гра міняє за рівнем речі.

Як зібрати заново: `tools/q/`.
- `itch_dl.sh` — завантажує набори з itch.io;
- `qcfg.py` — налаштування;
- `qmake.mjs` — збирання через gltf-transform.
